    What converts well
    • Word → PDF keeps headings, paragraphs, bold, italics, underline, lists, tables, links and embedded PNG/JPEG/GIF images. Page headers, footers, columns, text boxes and exact fonts are not reproduced; text is set in a clean standard font.
    • PDF → Word, editable text rebuilds paragraphs and headings from the PDF's text, with bold, italics, font sizes and page breaks. Complex multi-column layouts and tables come through as plain paragraphs.
    • PDF → Word, exact look places each PDF page into Word as a picture, so it looks identical but the text is not editable. Scanned pages with no text layer always come through this way.
    • Everything runs locally in this page. Nothing is uploaded.
